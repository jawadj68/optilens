Installer Optilens sur un autre PC (Windows)

1. Logiciels à installer

LogicielOù le trouverRemarque
Python {{ python_version }} python.org/downloads/windows Pendant l’installation, cochez « Add python.exe to PATH ». Prenez la même version que sur ce PC.
Git for Windows git-scm.com/download/win Options par défaut. Il inclut la connexion GitHub par navigateur.
Cursor (facultatif) cursor.com Seulement si vous voulez modifier le programme sur ce PC.

Rien d’autre n’est nécessaire : Django et les autres composants s’installent automatiquement à l’étape 3. Pas besoin de FileMaker sauf pour refaire un import.

2. Télécharger le programme

Ouvrez PowerShell (menu Démarrer → « PowerShell ») et tapez :

git clone {{ repo_url }} C:\Optilens

Le dépôt est privé : une fenêtre s’ouvre la première fois pour vous connecter à GitHub (compte jawadj68).

3. Préparer le programme

Dans l’Explorateur, ouvrez C:\Optilens\scripts et double-cliquez sur Setup Optilens.bat. Il crée l’environnement Python, installe les composants et prépare la base. Comptez quelques minutes.

4. Démarrer

Double-cliquez sur scripts\Run Optilens.bat, puis ouvrez http://127.0.0.1:8002/ dans le navigateur. Gardez la fenêtre noire ouverte tant que vous utilisez Optilens.

Copier les données patients

Les données patients ne sont pas sur GitHub (volontairement, pour la confidentialité). Elles sont dans un seul fichier :

{{ base_dir }}\data\optilens.sqlite3
  1. Sur ce PC, fermez Optilens (fenêtre noire), puis copiez ce fichier sur une clé USB.
  2. Sur l’autre PC, collez-le dans C:\Optilens\data\ (remplacez le fichier existant).
  3. Démarrez Optilens et connectez-vous avec le même utilisateur et mot de passe que sur ce PC.
Travailler sur deux PC

Le programme se synchronise par GitHub. Dans PowerShell, dans C:\Optilens :

  • Avant de commencer : git pull (récupère les dernières modifications)
  • Après avoir modifié le programme : git push (les envoie sur GitHub)
  • Après un git pull, lancez une fois Setup Optilens.bat si on vous signale des nouveautés (nouveaux composants ou nouvelles tables).
Les données ne se synchronisent pas. Si vous saisissez des patients sur les deux PC, les fichiers divergent et on ne peut pas les fusionner simplement. Choisissez un seul PC principal pour la saisie, et ne copiez la base que dans ce sens.
Lier les fiches cliniques (CS)
  1. Onglet Fiches non liées → Commencer la vérification.
  2. Comparez avec les patients proposés (le badge même tél. est un bon indice). Cliquez sur le nom pour ouvrir la fiche patient dans un nouvel onglet.
  3. Lier si c’est la bonne personne, Nouveau patient depuis cette fiche si elle n’existe pas, ou Passer en cas de doute.
  4. Les deux copies du dossier (CS et CS ancien) sont liées ensemble, puis la fiche suivante s’affiche.
Sauvegardes

Onglet Paramètres → Sauvegarder maintenant (au moins une fois par jour de saisie). Copiez régulièrement le dossier data\backups sur une clé USB.

Problèmes fréquents
« python n’est pas reconnu »
Python n’a pas été ajouté au PATH. Relancez l’installateur Python → Modify → cochez « Add Python to environment variables ».
« git n’est pas reconnu »
Installez Git for Windows, puis fermez et rouvrez PowerShell.
La page ne s’ouvre pas
Vérifiez que la fenêtre noire de Run Optilens.bat est ouverte et sans message d’erreur.
« no such table » ou erreur après une mise à jour
Relancez Setup Optilens.bat : il met la base à jour sans effacer les données.
Mot de passe oublié
Dans PowerShell, dans C:\Optilens : .\.venv\Scripts\python manage.py changepassword NOM_UTILISATEUR
